# التشغيل والإعداد — دليل مبسّط

## ما الذي تحتاجه؟

- **Node.js 22** أو أحدث.
- **PostgreSQL 16** (قاعدة بيانات).
- هذا المستودع.

## التشغيل على جهازك (تطوير)

```bash
npm install                 # تثبيت المكتبات
cp .env.example .env        # ثم افتح .env وضع روابط قاعدة البيانات
npm run db:migrate          # إنشاء الجداول
npm run db:seed             # إدخال قائمة الأسعار والموظفين الثمانية (بدون حسابات دخول)
npm run owner:invite -- --role=owner --username=doha   # يطبع رابط تفعيل حساب المالكة
npm run dev                 # افتح http://localhost:3000
```

1. افتحي الرابط الذي طبعه الأمر `owner:invite`، واختاري كلمة مرور.
2. سجّلي الدخول باسم المستخدم `doha` (أو الاسم الذي اخترتِه).
3. من «الموظفون» افتحي أي موظف ← «إنشاء حساب وإصدار رابط تفعيل» ← انسخي الرابط وأرسليه له بشكل خاص (واتساب مثلًا).
   - الرابط يعمل مرة واحدة وينتهي خلال 48 ساعة.
   - الأخصائيات تبدأ حساباتهن بالإنجليزية، والباقي بالعربية، ويمكن لكل شخص تغيير لغته من «حسابي».
   - نسيان كلمة المرور: «إصدار رابط جديد» من صفحة الموظف.

## قواعد البيانات المنفصلة

| المتغير | الاستخدام |
|---|---|
| `DATABASE_URL` | قاعدة التشغيل الفعلية (أو التطوير على جهازك) |
| `TEST_DATABASE_URL` | قاعدة **الاختبارات الآلية فقط** — تُمسح أثناء الاختبار. لا تجعليها نفس قاعدة التشغيل أبدًا. |

الاختبارات ترفض العمل إذا لم يكن اسم قاعدة الاختبار يحتوي كلمة `test`.

## الاختبارات

```bash
npm test          # كل الاختبارات (وحدات + تكامل على قاعدة الاختبار)
npm run lint      # فحص الأنواع TypeScript
```

## الأسرار

- الأسرار (روابط قاعدة البيانات، ولاحقًا مفاتيح Google Maps وتابي وتمارا) توضع **فقط** في ملف `.env` على الخادم أو في إعدادات منصة الاستضافة.
- ملف `.env` مستبعد من Git. لا تُلصق الأسرار في المحادثة أو المستودع.
- `.env.example` يحتوي أسماء المتغيرات فقط بدون قيم حقيقية.

## النشر على دومين واستضافة

الخطوات كاملة ومبسطة في **`docs/DEPLOY.ar.md`** (خادم واحد + Docker + HTTPS تلقائي + نسخ احتياطي يومي).

## النسخ الاحتياطي والاستعادة

```bash
./scripts/backup.sh                         # ينشئ backups/pamper-YYYYMMDD-HHMM.dump
pg_restore --clean --if-exists -d "$DATABASE_URL" backups/pamper-XXXX.dump   # استعادة
```

- ملفات النسخ تحتوي بيانات حساسة (رواتب وعملاء): تُحفظ في مكان آمن مشفّر، ولا تُرفع إلى Git (المجلد `backups/` مستبعد).
- جرّبي الاستعادة على قاعدة منفصلة مرة كل شهر للتأكد من صلاحية النسخ.
- في الاستضافة المُدارة فعّلي النسخ اليومي التلقائي مع الاحتفاظ 30 يومًا على الأقل.

## تثبيت التطبيق على الجوال (PWA)

> يعمل التثبيت فقط عندما يكون الموقع على HTTPS.

- **iPhone (Safari):** افتحي الموقع ← زر المشاركة ← «إضافة إلى الشاشة الرئيسية». الإشعارات على iPhone تتطلب iOS 16.4 أو أحدث **وفتح التطبيق من أيقونة الشاشة الرئيسية** (ليس من Safari مباشرة).
- **Android (Chrome):** افتحي الموقع ← القائمة ⋮ ← «تثبيت التطبيق» أو «إضافة إلى الشاشة الرئيسية».
- **الكمبيوتر (Chrome/Edge):** أيقونة التثبيت في شريط العنوان.

الإشعارات (Web Push) ومركز الإشعارات داخل التطبيق تُضاف في المرحلة 5، مع طلب الإذن بعد ضغطة واضحة من المستخدم.
