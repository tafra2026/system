## الحالة

| الجزء | الحالة |
|---|---|
| المراحل 1–4: الحسابات والصلاحيات، الخدمات والعملاء والطلبات، الفرق والمشاوير والتقويم، التحصيل والعهدة والعمولات والمصروفات والرواتب والتقارير | ✅ مكتملة ومختبرة |
| المرحلة 5: رسائل واتساب، مركز الإشعارات وإشعارات الجوال، العملاء المميزون | ✅ مكتملة ومختبرة |
| المرحلة 5: روابط تابي وتمارا من داخل التطبيق | ⏳ بانتظار مفاتيح التاجر (تُسجَّل يدويًا حتى ذلك الحين) |
| المرحلة 6: ملفات النشر (Docker + HTTPS تلقائي + نسخ احتياطي يومي) | ✅ جاهزة — [`docs/DEPLOY.ar.md`](docs/DEPLOY.ar.md) |
| المرحلة 6: التجربة مع الفريق على الخادم الفعلي | ⏳ الخطوة التالية |

> **جاهز للرفع والتجربة مع الفريق.** يُعتمد للاستخدام الكامل بعد أسبوع تجربة على الخادم الفعلي (HTTPS وإشعارات الجوال على أجهزة الفريق) وتفعيل ربط تابي وتمارا.
